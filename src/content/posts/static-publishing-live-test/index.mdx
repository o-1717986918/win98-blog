这是一篇真实公开的部署验证文章。它不是占位页，而是用于确认本站的新发布路线能够把一次普通内容变更完整送达公网。

## 本次验证什么

文章从内容仓库进入 GitHub Actions，在隔离环境中完成 Astro 构建、Pagefind 索引、链接检查与性能预算检查。验证后的静态产物会计算散列并上传到服务器，再由发布脚本校验文件结构、切换当前版本并执行本机冒烟测试。

服务器不拉取源码，也不安装 Node.js。宝塔只把 HTTPS 请求转发到只读静态容器，因此内容更新与运行环境保持分离。

## 验收标记

本次发布使用唯一标记：`WIN98-STATIC-PUBLISH-20260927`。

如果你能在文章页读到这段文字，并且能通过站内搜索找到这篇文章，同时在 RSS 与 Sitemap 中看到它，就说明下面这条链路已经贯通：

```text
内容提交 → Actions 构建与检查 → 产物上传 → 原子切换 → 公网访问
```

## 测试后的意义

这次验证完成后，日常发文只需要维护内容、推送仓库并触发一次发布工作流。生产服务器继续只负责验收和提供静态文件，旧版本则保留为可立即回退的发布记录。
