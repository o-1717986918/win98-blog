这里收录不只停在文本层的工具：有的在有界内存中搜索可执行路径，有的把教学策略、掌握度与复习状态写成 Agent 协议。文章会同时记录它们能做什么、怎样验证，以及哪些产品化缺口仍然存在。

主题不以“有一个界面”作为完成标准。求解器要能运行真实内核，Skill 要能说明状态如何持久化；演示、算法和工程边界会被分开表述。
