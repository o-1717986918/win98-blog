# Signature font subset

`site-signature.woff2` is an 8 KiB Google Fonts text subset of Noto Sans SC v40. It contains only ASCII uppercase letters, digits, and the six Chinese glyphs used by “某人的小站”. The site uses it only for identity lockups; arbitrary article titles and body text continue to use the local system stacks.

- CSS API source: `https://fonts.googleapis.com/css2?family=Noto+Sans+SC:wght@600;700&display=swap&text=...`
- Binary host: `fonts.gstatic.com`
