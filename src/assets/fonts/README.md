# Signature font subset

`site-signature.woff2` is an 8 KiB Google Fonts text subset of Noto Sans SC v40. It contains ASCII uppercase letters, digits, and the Chinese glyphs shared by the original identity and “win98的小站”; lowercase Latin letters intentionally fall through to the signature stack's local display fonts. The site uses it only for identity lockups; arbitrary article titles and body text continue to use the local system stacks.

- CSS API source: `https://fonts.googleapis.com/css2?family=Noto+Sans+SC:wght@600;700&display=swap&text=...`
- Binary host: `fonts.gstatic.com`
