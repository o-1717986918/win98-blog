# ADR-0001：接手基线与源资产保护

状态：Accepted

日期：2026-08-28

## 背景

源目录只包含架构文档和单文件原型，没有 Git 历史。直接在源目录继续修改会混淆原始设计、迁移过程和正式实现。

## 决策

- 在独立 `wenshu-blog` 仓库接手；
- 将源文件按原内容复制到 `docs/source/` 与 `prototype/`；
- 用 SHA-256 和 `pnpm check` 固定基线；
- 外部源目录保持只读；
- 正式 Astro 实现将在后续 Gate 中新增，不覆盖原型基线。

## 后果

优点：保留可核对的设计证据，迁移差异可追踪，源项目无风险。

代价：正式实现期间会暂时同时存在原型和生产代码；必须清楚标注两者权威边界。
