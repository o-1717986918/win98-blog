# ADR-0011：本地工程闭环与双主题收束

日期：2026-08-28

状态：已接受

## 决定

1. 视觉主题只保留 `mist` 与 `abyss` 两套实际令牌；旧的 `paper` 输入兼容映射到 `mist`，`graphite/night/indigo` 映射到 `abyss`，但不会形成额外的页面主题。
2. 首页重点文章在宽屏采用左文右图，指针只驱动局部光斑与封面的微小位移；触屏和减弱动态环境不启用。
3. 首页栏目轨道在宽屏与文章列表保持近似等高，独立纵向滚动并使用交错卡片；站点事实条增加文章、栏目、阅读量、外壳分布与标签信息。
4. 无真实图片的内容在构建期生成 1200×630 的主题化 PNG 分享图；页面内仍使用确定性 SVG 默认封面。
5. 正式提供 Callout、DataChart 与 CodePlayground 三种 MDX 组件；图表具有文本数据表，代码预览在 sandbox iframe 中运行。
6. Waline 用户内容运行在无 `allow-same-origin`、无顶层导航权限的 iframe 内，并强制服务地址为 HTTPS。
7. full/minimal 页面启用跨文档 View Transitions；none 不导入相关 CSS，继续保持资源隔离。
8. 阅读控件默认收起，增加行距档位与逐路径的阅读位置恢复。
9. Playwright 在 CI 覆盖 1280×720、390×844、开场焦点隔离、搜索、三档外壳、阅读偏好和减弱动态；封面资产由独立脚本审计。

## 理由

四套相近主题增加维护面，却没有产生四种足够不同的阅读目的。两套主题能把选择明确为“雾面日间”与“深渊夜间”。动态效果被限制在首页主文章局部，避免重新制造全页跟随光效。构建期分享图、浏览器回归和资产审计补齐了上线前最关键的自动化缺口。

## 边界

真实封面创作、生产域名、Cloudflare 项目、评论/统计账号和上线后的网络请求核验依赖站主提供的外部状态，不属于本地仓库可以独立完成的工作。
