# ADR-0008：顶栏轻量发现与色域景深

状态：Accepted

日期：2026-08-28

## 决策

- 搜索不再使用模态弹窗或首页大模块，而收纳为顶栏中的单一输入框；即时结果只以非模态暂态层出现。
- `/search/` 作为旧深链的兼容说明页，不重复搜索交互。
- 首页最新文章与文章列表的根元素本身是原生 `<a>`；卡内栏目和标签作为展示性元数据，避免嵌套链接或透明覆盖层破坏布局与命中。
- 取消彩色长条、卡片侧边色条和四格色块图标。顶栏、文章流与栏目卡片分别使用雾蓝、陶杏、鸢紫和柔金的明确纯色表面；最大重点文章仍保留低对比冷暖渐变，避免它变成突兀色块。圆点和轨道符号只承担低权重状态提示。
- 背景视角反馈同时作用于 CSS 色域和 PixiJS 粒子；偏移量由粒子深度加权，不变换正文或点击坐标。

## 理由

编辑式博客的核心是连续阅读，搜索应随手可得但不能取得与文章相同的视觉权重。仅在小线条上使用主题色又会让页面继续呈现单色；因此各主要模块拥有稳定、可辨认的表面色，背景景深继续保持低对比，搜索则保持顶栏工具的尺度。

## 后果

搜索不再增加首页高度，也不需要焦点陷阱或遮罩层；小屏上输入框随导航展开，有结果时才占用垂直空间。减弱动态、手动暂停与视口隐藏规则继续优先于视角效果。
