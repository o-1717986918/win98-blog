# ADR-0004：单文件视觉候选只作为过程实验

状态：Superseded by ADR-0006

日期：2026-08-28

## 背景

项目曾从冻结原型副本探索现代技术编辑式视觉，用于验证配色、移动导航和文章层级。该候选仍是单文件 hash 路由，不能代表 `blog-architecture.md` 要求的真实生产架构。

## 决策

- 候选保留在 `experiments/single-file-visual-candidate/`，只作过程证据；
- 生产主线从原版结构和架构结论重新落实到 `src/`，不从 Celestial Matrix 或单文件候选派生架构；
- 可复用的结论仅限低饱和语义色、清晰文章索引、克制背景与现代技术文案；
- 公开身份、栏目模型、真实 URL 和三档外壳由正式 Astro 工程重新实现。

## 后果

实验可以继续存在，但不得被 README、预览命令或接手状态称为主线。生产验收只针对 `src/` 和 `dist/`。
