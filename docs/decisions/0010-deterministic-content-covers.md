# ADR-0010：内容封面采用真实图片优先、确定性校样图兜底

状态：Accepted

日期：2026-08-28

## 决策

- 文章与栏目在发现界面和标准阅读页中始终拥有封面空间。
- frontmatter 的 `cover` 仍是可选的真实图片覆盖；缺省时由 `ContentCover.astro` 根据内容类型、稳定 ID 和栏目 accent 生成 SVG 校样封面。
- 默认封面使用套色块、裁切线、校样窗口和登记条，不生成随机插画，也不把标题绘进图片。
- 首页重点文章、文章流、栏目目录、相关文章和 full/minimal 正文共享同一封面组件；`chrome:none` 页面保持零外壳契约，只在站点发现界面显示默认封面，页面内部由内容作者决定。

## 理由

真实摄影或插图应该属于内容作者，不能由站点伪造。另一方面，完全无图会让内容框退化成同质化文字容器。确定性默认封面能够建立稳定身份、增加色彩面积，并保证列表重排或重新构建后不变。

内联 SVG 还避免为每篇草稿生成和维护一张无意义的位图；作者一旦提供 `cover.src` 与准确的 `cover.alt`，同一组件会自动切换到 Astro 图片管线。

## 后果

- 默认封面不是 OG 分享图；按文章主题生成 OG 图片仍是独立工程项目。
- 重要文章仍应优先提供与正文有关的真实图片，默认封面只负责结构完整与视觉识别。
- `none` 内容若希望封面进入独立页面，必须在自己的 MDX/Astro 页面中显式使用封面或其他首屏视觉。
