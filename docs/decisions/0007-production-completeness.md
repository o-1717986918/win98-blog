# ADR-0007：以静态核心和可选适配器完成生产交付

状态：Accepted

日期：2026-08-28

## 决策

- 正文、分类、搜索索引、SEO、RSS 与分享资源全部在构建期完成；
- 管理工作流以 Git、脚手架、草稿预览和 CI 为核心，不引入在线 CMS 运行时；
- 评论和统计通过环境配置适配器接入，默认关闭；
- `none` 文章/栏目继续只拥有 BaseLayout、私有内容与可选返回桥；
- 参考部署选择 Cloudflare Pages 静态构建，同时保留 GitHub Pages/通用静态主机能力；
- 背景 Canvas 允许持续缓慢运动，但必须支持手动暂停、系统减弱动效和页面隐藏暂停。

## 理由

这套边界能同时满足管理者的发布/回滚、读者的发现/阅读和长期低维护，并避免为了在线后台、评论或统计破坏既有的三档外壳与静态部署能力。

## 后果

首次公网部署仍需配置域名及可选第三方账号；这些外部状态不能写入仓库。多人非技术编辑若成为真实需求，可在纯文本集合上另行评估 Decap CMS，而不改变文章核心存储。
