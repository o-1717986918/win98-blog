# ADR-0009：以光谱批注场统一视觉，并让色彩归属内容

状态：Accepted

日期：2026-08-28

## 决策

- 保留首页会话级开场和全站粒子能力，但把表达从“星空”改为短划、方点和批注轨迹；开场不再长时间阻塞内容，并在显示期间隔离底层交互与辅助技术树。
- 首页重点文章改为紧凑的“批注页签”。桌面降低高度与标题尺度，移动端控制为可在一个视口内完整理解的内容单元。
- 全站色彩遵循中性底色为主、钴蓝负责导航与可操作信号、柿红负责进入与修订、鸢紫负责引用、赭金负责索引的分工。
- 栏目新增稳定的 `accent` 数据。文章列表继承其首个栏目 accent；栏目与文章不再按列表位置轮换颜色。
- 粒子在正文阅读表面附近降低存在感，减弱动态或手动暂停时不初始化 PixiJS。
- 搜索默认只返回文章，并只索引文章正文；聚合页、导航、相关文章和工具文本不参与正文检索。

## 理由

现有视觉元素单独完成度较高，但开场、星空、玻璃焦点卡、四色卡片和轨道圆点共同争夺注意力，形成常见的生成式技术站语法。V4 不删除视觉能力，而把它们收束到“技术笔记被持续批注和修订”这一种可解释的材料来源中。

稳定 accent 也使“主题是数据”从页面背景延伸到内容发现层：重排列表不会改变一篇文章或一个栏目的色彩身份。

## 后果

- 新栏目可选择 `aqua / coral / violet / gold` 四种 accent；省略时使用 `aqua`。
- 第一栏目同时承担文章的主要策展路径和列表色彩来源，文章需要按重要性排列 `columns`。
- 开场仍是品牌体验，但必须可跳过、可键盘退出、尊重减弱动态，并自动恢复底层页面的可操作性。
- 视觉回归需覆盖 1280×720 与 390×844 的首页、full 文章、minimal 文章和 none 页面。
