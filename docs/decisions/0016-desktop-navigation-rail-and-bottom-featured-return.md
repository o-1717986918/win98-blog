# ADR-0016：桌面导航侧栏与末尾精选回看

- 状态：Accepted
- 日期：2026-08-30

## 背景

首页已经具备个人门户骨架，但横向顶栏继续强化了“公司主页”观感，且重点文章即使压缩后仍占据进入内容前的大块空间。用户要求把顶栏重构为侧栏，并将重点区域移到底部，同时保留本站既有视觉语言。

## 决策

1. `full` 外壳在宽度不小于 1101px 时使用 13rem 固定左侧导航轨道；主内容与页脚显式避让该轨道。
2. 导航轨道由顶部独立搜索、品牌、站点说明、分层导航、背景动效与主题切换组成；二级导航依 ADR-0017 在侧栏内部展开，只有搜索结果向右展开并受视口边界约束。
3. 1100px 及以下继续使用顶部折叠菜单，避免侧栏压缩移动端阅读宽度。
4. 首页在身份说明和状态条后直接进入门户；压缩后的重点文章移动到门户之后，语义调整为“精选回看”，封面采用延迟加载。
5. 侧栏仍使用 mist/abyss、细线、登记色、原品牌图与等宽标注，不复制 Mizuki 的圆角玻璃卡片和常驻壁纸。
6. `minimal` 与 `none` 外壳不引入站点侧栏，既有样式和脚本隔离契约保持不变。

## 后果

- 桌面站点获得更稳定的个人门户导航骨架，中央内容不再被横向顶栏切断。
- 首页首屏优先呈现资料、文章和学习入口，重点文章不再与主门户争夺视觉层级。
- 固定侧栏增加少量全壳样式，因此单页原始 CSS 上限记录为 80 KiB；路由隔离、移动端回流、侧栏飞出菜单与 320px 无横向溢出由自动化测试守护。
