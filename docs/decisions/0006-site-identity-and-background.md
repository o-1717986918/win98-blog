# ADR-0006：简朴站名与受约束的现代背景

状态：Accepted

日期：2026-08-28

## 决策

- 站点公开名固定为“win98的小站”；视觉方向、栏目名和实验名都不能取代站名；
- 视觉重构主要落在语义配色、环境背景、排版比例、留白和交互细节，不改变个人博客的信息结构；
- 主主题采用石墨中性色，青绿只作为信号色，暖色只作少量强调；另外提供 paper、night、indigo 三套等价主题；
- 背景采用 CSS 静态网格/柔和色场与一次绘制 Canvas；不使用持续装饰动画，不让 Canvas 承担内容；
- 星图和相位图只属于具体实验，不成为品牌、首页 hero 或栏目分类体系。

## 理由

简朴名称让长期内容而非一次性概念承担身份。把视觉创新限制在可降级的配色和背景层，既保留原版的环境感，也不破坏文章主体、静态优先和渐进自由。

## 验证

正式源代码、页面标题、导航、RSS 与 sitemap 禁止出现历史候选名；构建测试检查 none 隔离与公开身份。背景必须支持主题重绘、减弱动效和无 Canvas 降级。
