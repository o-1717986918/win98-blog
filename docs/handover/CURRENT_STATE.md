## 实测结果

在 Chromium 内核浏览器通过本地 HTTP 服务检查：

- 桌面视口 1280 × 720：首页、文章页和粒子实验页均正常渲染；
- hash 路由、主题选择、文章目录生成、阅读字号、返回桥和 Canvas 动画能够工作；
- `chrome:none` 原型页隐藏了头部与页脚，并保留返回桥；
- 390 × 844 下文章页与实验页无横向溢出；
- 控制台未发现 error 或 warning。

已知问题：

1. 390px 移动视口的首页顶栏发生横向溢出：页面 `scrollWidth=500`，`clientWidth=380`；品牌、三项导航和按钮没有移动端收拢策略。
2. 原型使用 `#/post/...` hash 路由，无法满足正式站的规范 URL、SEO、sitemap 和 RSS 契约。
3. `none` 页在原型中仍共享同一份全局 CSS/JS 和 Canvas 背景运行时，只验证了视觉上的无外壳，尚未证明生产级“零全局注入”。
4. 帮助浮层和主题菜单缺少完整的对话框/菜单键盘语义、焦点捕获与 `aria-expanded` 状态。
5. 内容以内嵌 HTML 字符串存在，无法获得 MDX、schema、图片管线和构建期验证能力。
