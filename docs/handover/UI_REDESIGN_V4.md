# UI 重构 V4：光谱批注场

状态：Approved for implementation  
日期：2026-08-28

## 1. 具体对象

“win98的小站”是一册公开生长的个人技术笔记，面向愿意阅读完整判断与实现过程的技术读者。首页只有一个任务：让读者在十秒内找到并进入一篇文章。

## 2. 材料来源

视觉不再从通用的星空、玻璃卡片或科技仪表盘取材，而从四种真实材料取材：

- 代码 diff 的边栏与变更痕迹；
- 编辑批注的短划、方点与校对标记；
- 印刷套色中的稳定色版；
- 长文阅读留下的页边轨迹。

## 3. 色彩系统

默认明亮主题的基准色：

| 角色 | 名称 | 色值 | 用途 |
|---|---|---|---|
| 背景 | 冷雾纸 | `#E7ECEB` | 页面环境与大面积留白 |
| 正文 | 碳墨 | `#17262E` | 标题与正文 |
| 信号 | 钴蓝批注 | `#3579A8` | 导航、焦点和链接 |
| 动作 | 柿红修订 | `#C66A43` | 进入文章与主动操作 |
| 引用 | 鸢紫引用 | `#6F6A9B` | 引用、阅读类内容 |
| 索引 | 赭金索引 | `#A28449` | 日期、计数和目录 |

面积分布约为 80% 中性色、12% 钴蓝、6% 柿红、2% 鸢紫与赭金。四种 accent 是内容身份，不是装饰轮播。

## 5. 签名元素

唯一主签名是“迁移的批注粒子”：开场中的文字粒子散开后，视觉上转化为页面边缘的短划、方点和轻微轨迹。正文上方与阅读表面保持安静，粒子不再模拟星空，也不承担第二套内容层级。

## 6. 明确删减

- 删除没有信息含义的轨道圆点；
- 删除列表按位置循环的四色实心卡片；
- 焦点文章不再使用大面积玻璃渐变和夸张 3D 舞台；
- 微型标签提高字号与对比度；
- 移动端固定控制器合并为更小的阅读托盘，并给正文预留安全区。

## 7. 验收

- 开场自动时长不超过约 4 秒，底层页面在开场时不可聚焦且不进入辅助技术树；
- 390×844 首屏可完整看到重点文章的标题、摘要和进入动作；
- 同一栏目和继承该栏目的文章在不同列表中保持稳定 accent；
- 搜索同一主题时，结果优先且默认只出现文章，不出现首页和标签聚合页；
- 减弱动态或已手动暂停时不下载和初始化 PixiJS 主引擎；
- 普通小字在各主题中达到 WCAG AA 对比度目标；
- full、minimal、none 的构建隔离保持不变。
