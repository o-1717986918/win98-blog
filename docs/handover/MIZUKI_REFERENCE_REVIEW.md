# Mizuki 参考边界与归档设计结论

日期：2026-08-30

## 结论

Mizuki 是一个功能覆盖很广的 Astro 主题：公开仓库列出了可配置侧栏、横幅与壁纸、Pagefind、丰富 Markdown/MDX、相册、日记、友链、项目与时间线等能力；归档实现按年份分组，以日期—轨道—标题—标签构成紧凑时间线。它适合需要“开箱即用个人门户”的用户。

“某人的小站”向综合个人门户发展，因此采用 Mizuki 的信息架构与功能组织思路；差异化仍是文章主体、证据驱动出版、三档外壳和单篇网页自治。这里的“贴近”指布局和功能，不是复制主题皮肤。

## 吸收

- 年月时间线：归档在构建期按发布时区生成年份与月份分组；日期、标题、类型、主题和标签保持可扫描。
- 空间效率：归档不再重复完整封面卡，改为技术出版时间尺，让 24 篇以上文章仍能快速浏览。
- 配置与内容分离：延续本站 Content Collections、主题数据与 Blog Studio，而不是把页面内容硬编码进模板。
- 专用页面的渐进扩展：项目、能力和时间线已有站内证据，因此首批启用；相册、日记等仍等待真实内容，不为功能清单创建空页面。
- 门户骨架：首页在身份说明与状态条后直接进入左侧身份与主题、中央写作时间流、右侧紧凑笔记与发现入口的三栏结构；中屏两栏、移动端单栏，重点文章移至内容末尾作为精选回看。
- 稳定导航：桌面端使用固定左侧导航轨道，移动端保留顶部折叠导航；只借鉴 Mizuki 的个人门户路径，不复制其卡片皮肤。
- 真实侧栏能力：发表日历由文章日期构建，标签显示真实计数，入口只指向已有可用页面。
- 综合功能路线：项目、能力、时间线已经接入；日记、相册、友链、追番、设备、AI 工具、音乐、Live2D 与壁纸继续作为关闭的注册项，每项都必须先有真实内容和性能边界。

## 不吸收

- 不加入 Tailwind、Svelte、Swup 或整站客户端导航；现有原生 CSS、静态 HTML 和跨文档原生转场继续作为实现底座。
- 不用空页面伪装功能完成；音乐、Live2D、壁纸等动态模块默认关闭并按路由懒加载。
- 不把每项能力都塞进顶栏；搜索、归档、主题与 Notes 继续各自承担明确的内容发现任务，扩展能力进入门户组件或专用页面。
- 不把 Mizuki 的圆角卡片语言复制到本站。时间关系借其结构，视觉仍使用本站的细线、刻度、等宽数据与语义 accent。

## 实现落点

- `src/lib/archive.ts`：发布时区日期拆分与年月分组。
- `src/components/ArchiveTimeline.astro`：无客户端依赖的双刻度时间尺。
- `src/components/PostSearch.astro`：筛选后同步隐藏空月份和空年份。
- `src/lib/archive.test.ts`、`tests/e2e/site.spec.ts`、`scripts/check-build.mjs`：分组、筛选、320px 回流和构建产物契约。

## 局部贴近实验：文章阅读航线

文章页继续使用本站原有正文网格，只把 Mizuki 的“上下文侧栏”概念收敛为桌面端阅读航线：构建期目录提供静态锚点，轻量脚本增强当前章节、章节序号、正文百分比和垂直轨迹。它不是可堆叠组件面板，也不引入新的数据源或运行时框架。

- `src/components/chrome/TableOfContents.astro`：输出可无脚本使用的目录，并渐进增强当前章节状态。
- `src/components/ArticleTools.astro`：以正文区域而非整页高度计算阅读进度，同时驱动顶部进度条和侧栏轨迹。
- `src/styles/prose.css`：使用开放式细线、刻度点与等宽数据延续本站技术出版语言；宽度低于 980px 时移除侧栏。
- `src/tests/architecture.test.ts`、`tests/e2e/site.spec.ts`：守住静态回退、桌面章节状态、移动端隐藏、进度保留和无横向溢出。

这轮实验确立的边界继续适用于文章页：上下文侧栏只服务长文阅读，不变成可堆叠组件面板。首页门户是独立的信息发现场景，可以使用响应式双侧信息栏。

## 局部贴近实验：独立个人资料卡

首页采用 Mizuki Profile 的信息结构：头像作为 About 入口，并呈现姓名、简介、当前项目、公开内容统计与个人链接。资料卡保持带切角、圆形头像和登记线的作者档案形态，位于门户左侧；“学习笔记”不再占据中央展示位，而收束为右侧知识入口。本站不复制其 Tailwind 卡片皮肤和动态打字效果，而使用既有 mist/abyss 令牌、出版刻度和真实内容计数。

顶栏左上品牌不再打开个人资料弹窗，改为稳定的首页链接。个人信息只在首页资料卡与 About 页面承担，顶栏重新保持单一导航职责；窄屏时按个人资料、学习笔记、最近写作、长期主题与发现入口的顺序回流。

## 门户实验：结构贴近、视觉守恒

首页在状态条后直接使用三栏门户，把内容发现提到首屏；重点文章压缩后下移到门户末尾，成为完成浏览后的精选回看。作者档案本体保持既有设计，中央只承担连续文章时间尺，学习笔记以紧凑形态进入右栏；主题收束为左侧可扫描索引，右侧月历、标签计数与目录均来自真实数据。窄屏顺序调整为作者、笔记、写作、主题和发现，更接近个人博客的阅读路径。

新增组件仍只消费 `mist/abyss` 语义令牌，采用 1px 规则线、切角、登记号与等宽数据。没有引入 Mizuki 的色板、图标、圆角玻璃卡、打字动效或常驻壁纸，因此可以扩展门户功能而不丢失本站视觉身份。

## 功能贴近：可操作而非陈列

- 首页文章时间流完整输出 23 篇非焦点文章；有脚本时先显示六篇并按六篇继续展开，无脚本时全部可读。
- 发表日历的活跃日期可直接筛选中央文章流，筛选状态与清除动作同步反馈。
- 原生门户设置可控制长期主题、发表日历、标签与站内入口的显隐，并在标准/紧凑密度间切换；偏好只保存在本机浏览器。
- `/projects/`、`/skills/`、`/timeline/` 是真实功能页，数据连接现有主题、文章、公开笔记与交互实现；时间线支持类别筛选。
- `src/config/portal.ts` 是功能注册表，明确区分已启用能力和等待内容的能力，防止页面清单领先于真实内容。
