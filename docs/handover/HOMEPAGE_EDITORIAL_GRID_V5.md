# 首页编辑式网格 V5

状态：2026-08-29 已实施并通过构建、E2E、1920×1080、390×844 与 320px 窄屏验收  
范围：首页桌面尺度、模块顺序、主题轨道、继续阅读封面与学习笔记入口。

## 1. 实测问题

在 1920×1080 视口中，首页主体宽度已经达到 1536px，重点文章封面约为 765×430px，因此“桌面端整体放大”已经成立。真正未达标的是下半区的相对尺度：

- 主题区宽约 1068px，继续阅读区只有约 356px；
- 继续阅读封面只有约 136×77px，既看不清真实界面，也无法承担文章识别；
- 学习笔记虽然是 1488×400px 的大模块，却先于主题出现，打断了“先理解站点长期主题，再进入个人知识库”的路径；
- 主题与继续阅读被强制等高，但卡片语义不同，等高没有产生秩序，只产生了机械对齐；
- 首页目前的错落主要来自外边距，模块之间仍像纵向堆叠的几个独立成品，缺少一条贯穿全页的编辑网格。

## 2. 视觉方向

对象仍是“公开生长的个人技术博客”。首页的单一任务不是展示所有功能，而是让读者先看到一篇代表作，再沿长期主题或最近文章继续深入。

### 色彩

不新增主题与渐变色。继续沿用：

- 冷雾纸 `#E7ECEB`：环境；
- 碳墨 `#17262E`：正文；
- 钴蓝 `#3579A8`：导航与焦点；
- 柿红 `#C66A43`：进入动作；
- 鸢紫 `#6F6A9B`：知识与引用；
- 赭金 `#A28449`：索引与时间。

### 版式

```text
桌面 / 12 列编辑网格

┌──────────────────────────────────────────────────┐
│ 站点身份                                  统计摘要 │
├──────────────────────────────────────────────────┤
│ 最近重点文章：左文案 / 右侧完整 16:9 大封面       │
├──────────────────────────────────────────────────┤
│ 内容信号：文章 / 阅读量 / 更新 / 高频主题          │
└──────────────────────────────────────────────────┘

┌──────────────────────────────┬───────────────────┐
│ 主题主轨（约 2fr）            │ 继续阅读（约 1fr） │
│ 独立纵向滚动                  │ 三张大封面卡       │
│ 横向主题卡：封面 + 说明       │ 封面完整、标题在下 │
│                               │ 整列轻微下错位     │
└──────────────────────────────┴───────────────────┘

        ┌──────────────────────────────────────────┐
        │ 学习笔记：向右错位的大型知识入口          │
        └──────────────────────────────────────────┘
```

移动端保持内容顺序：重点文章 → 内容信号 → 主题 → 继续阅读 → 学习笔记。所有双栏回流为单列，错位取消。

## 3. 关键决定

1. **继续阅读不再使用缩略图目录行。** 三篇文章改为纵向大图卡，每张卡都给完整 16:9 封面；真实截图必须能被辨认，而不是只证明“这里有图”。
2. **主题与近文不再等高。** 主题轨道按其六个长期入口形成独立滚动窗口；近文按三张大卡自然生长，二者只共享上边界附近的节奏，不共享卡片尺寸。
3. **学习笔记后置并右移。** 它是站主工具的公开投影，不应抢在博客主题之前；右侧错位让它成为第二阅读路径，也避免再次形成满宽大横幅的模板感。
4. **重点文章继续是唯一视觉主角。** 不为其他模块复制它的超大标题和动态效果；主页的大胆投入只花在重点文章与一次网格错位上。
5. **封面完整性保持不变。** 所有封面仍处于稳定 16:9 画布并使用 `contain`；正文媒体继续按固有比例排版，不继承封面规则。

## 4. 批判性自检

- 如果把右栏三张卡都做成与重点文章同等级的大卡，首页会变成海报墙。因此近文封面增大，但标题、日期与动作保持克制。
- 如果学习笔记继续放在重点文章后，它会把长期主题推到第二屏以后，错误地把维护工具放在内容结构之前。因此改到主题与近文之后。
- 如果为了“整体放大”继续扩大正文行宽，会损害长文阅读；新增空间只分配给封面、主题轨道与功能模块。
- 如果主题卡也改成纵向海报，六个主题的滚动成本过高。主题仍采用横向卡，但封面宽度提高，和右栏近文形成明确差异。

## 5. 验收条件

- 1920px 视口首页主体继续保持约 1536px；重点文章不缩小。
- 继续阅读栏宽度不低于约 420px，三张封面在桌面端宽度不低于约 380px。
- 继续阅读严格三篇；每张卡的封面为完整 16:9，不发生主体裁切。
- 主题区位于左侧并明显大于近文区；主题列表独立纵向滚动。
- 学习笔记位于主题/近文之后，桌面端向右错位，移动端恢复满宽。
- 390px 和 320px 不产生页面级横向滚动；卡片回流后仍保持完整封面。
- 键盘焦点、减弱动态、mist/abyss 与现有路由契约不回退。
