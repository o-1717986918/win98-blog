# 功能完整与可部署交付计划

状态：已完成

日期：2026-08-28

## 1. 目标与边界

目标不是把博客做成后台应用，而是在既定 `blog-architecture` 下形成完整闭环：管理者可以创建、预览、审查、发布、回滚和观察内容；读者可以发现、阅读、搜索、订阅、分享与按需互动；项目可以在无外部服务时完整构建，并能配置后部署到静态托管平台。

公开站名、文章主体、栏目一等集合、`full/minimal/none`、`BaseLayout` 空骨架、内容共置和 `none` 零全站注入继续是硬约束。

## 2. 需求地图

### 管理者

| 工作 | 必须具备 |
|---|---|
| 建内容 | 文章/栏目脚手架、合法 slug、frontmatter 模板、共置资产目录 |
| 控制发布 | draft、发布日期、未来文章不上生产、开发环境可预览 |
| 维护分类 | 栏目引用校验、标签索引、相关文章自动计算 |
| 保证质量 | 类型、链接、资源、SEO、RSS、搜索、三档隔离和构建产物测试 |
| 发布与回滚 | CI、预览构建、静态产物、部署说明、环境变量清单、Git 历史 |
| 观察运营 | 可选隐私统计、评论审核入口、错误/性能指标说明 |
| 保持所有权 | 内容与媒体留在仓库；外部服务全部可关闭、可替换、失败可降级 |

### 读者

| 任务 | 必须具备 |
|---|---|
| 找内容 | 首页、栏目、标签、归档、全文搜索、相关文章 |
| 判断是否阅读 | 标题、摘要、日期、更新时间、时长、栏目、标签、封面/分享信息 |
| 舒适阅读 | 响应式正文、目录、进度、字号、沉浸、明暗主题、动效暂停 |
| 获取和传播 | RSS、复制链接、系统分享、稳定 canonical、OG/Twitter 卡片 |
| 参与互动 | 可选评论；无账号或服务不可用时不影响正文 |
| 信任网站 | 隐私说明、语义 HTML、键盘可用、减弱动效、快速稳定加载 |

## 3. 方案取舍

1. **内容管理采用 Git-first。** 当前文章允许 MDX 与私有 Astro 组件共置，通用富文本 CMS 无法无损表达。主线提供 `content:new`、草稿预览、审计与文档；Decap CMS 留作将来多人纯文本栏目选配。Keystatic 不进入主线，因为其 Astro 在线管理需要服务端适配器，并引入 React/Markdoc，与静态 MDX 目标冲突。
2. **搜索采用 Pagefind。** 构建后索引静态 HTML，只索引正文，栏目/标签作为过滤数据；支持中文分词，不建立搜索后端。
3. **代码采用 Expressive Code，图片采用 Astro Assets。** 两者都在构建期工作；代码主题映射语义主题，图片强制尺寸与替代文本，避免 CLS。
4. **评论和统计是适配器，不是基础依赖。** 评论支持 `none / giscus / waline` 配置，统计支持 `none / cloudflare / umami` 配置；未配置时没有网络请求，`none` 页面永不加载这些服务。
5. **静态托管优先。** 参考部署为 Cloudflare Pages：`pnpm build`、输出 `dist`、PR 预览；GitHub Pages 作为无外部运行时的备选。保持无 Astro SSR adapter。
6. **保留并加强背景动效。** 环境 Canvas 恢复缓慢运动，提供暂停、持久化与 `prefers-reduced-motion` 静止分支；它永远不承担内容。
7. **配色只做附加改良。** graphite/indigo 提升背景明度、表面层次与信号色可见度，保留 paper/night 的功能分工，不重写页面结构。

## 4. 实施 Gates

### Gate A：内容运营基础

- 扩展站点和文章 schema：作者、封面、更新时间、精选、评论开关、索引开关、许可信息；
- 发布判定同时处理 `draft` 与未来日期，开发环境仍能预览；
- `content:new post|column` 生成合法共置目录；
- 内容审计检查引用、slug、日期、图片 alt、内部链接与重复 canonical。

退出条件：管理者无需复制旧文章即可创建内容；错误或未来内容不会误发布。

### Gate B：发现与阅读

- 新增标签目录和标签详情页；
- Pagefind 全文搜索页，支持栏目/标签过滤与无脚本说明；
- 相关文章、阅读进度、分享/复制链接；
- 首页保留快速过滤，并把全站搜索作为明确入口。

退出条件：任意发布文章可从首页、归档、栏目、标签、搜索或相关文章至少一种路径到达。

### Gate C：富内容与可发现性

- Astro 图片组件与封面 schema；
- Expressive Code 多主题代码块；
- canonical、Open Graph、Twitter Card、BlogPosting/WebSite/Person JSON-LD；
- robots、web manifest、favicon、RSS 完整字段、`llms.txt` 内容入口；
- 自动生成默认 OG SVG；文章可覆盖封面。

退出条件：页面元数据可验证、分享有卡片、图片不引入布局跳动、代码可复制且主题可读。

### Gate D：互动、隐私与视觉附加轨

- 评论适配器按文章与环境配置懒加载；
- 统计适配器仅 full/minimal 的站点页面按配置注入；
- 隐私页说明真实启用项；
- 恢复背景缓慢动效并增加暂停控制；
- graphite/indigo 提亮，完成对比度、桌面/移动和减弱动效审查。

退出条件：无配置零第三方请求；none 产物隔离测试继续通过；动效可停且偏好可记忆。

### Gate E：部署与运维闭环

- `.env.example`、部署前检查、Cloudflare Pages 与 GitHub Pages 指南；
- CI 执行冻结安装、测试、类型、构建、Pagefind、链接与产物契约；
- 静态安全头、404、缓存策略与回滚说明；
- 性能预算：标准页 LCP≤2.5s、INP≤200ms、CLS≤0.1 为实测目标，另设 JS/CSS/图片体积门槛；
- 最终浏览器验收 390×844、1280×720、键盘、无 JS、减弱动效和代表页面。

退出条件：全新 clone 只需环境变量即可构建；静态产物可上传任意静态主机；参考平台配置可直接使用。

## 5. 不纳入本轮

- 登录、在线写作后台、数据库文章、付费墙、邮件营销自动化、PWA 离线缓存；
- 为评论或统计把整站改成 SSR；
- 未经真实需求引入多作者权限系统；
- 对 `none` 页面自动注入搜索、评论、统计、阅读或背景服务。

## 6. 外部配置而非代码阻塞

最终公网发布仍需要站主提供真实 `SITE_URL` 与托管账号。Giscus 需要公开 GitHub Discussions 仓库；Waline 需要服务端和数据库；统计需要 Cloudflare token 或 Umami URL/站点 ID。这些缺失时项目仍以“功能关闭”方式完整构建和部署。

## 7. 研究依据

- Astro 官方建议静态构建输出 `dist`，Content Collections schema 在构建期校验内容；
- Pagefind 支持 `data-pagefind-*` 控制正文、元数据、栏目/标签过滤，并支持中文分词；
- Google 建议文章使用完整准确的 JSON-LD，并以 LCP、INP、CLS 的 75 分位监控真实用户体验；
- Giscus 适合 GitHub 技术读者，Waline 提供匿名评论、审核和多数据库；二者需求不同，因此不能硬编码为唯一方案；
- WCAG 要求持续自动动效提供暂停/停止机制，因此背景动效必须与可访问性控制一同交付。
