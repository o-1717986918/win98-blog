# 内容封面系统

日期：2026-08-28

## 视觉方向

默认封面是一张“印刷校样片”，材料来自套色、裁切标记和版面窗口。它不模拟摄影，也不批量制造 AI 插画。颜色继承内容稳定 accent，并配对另外两块语义色，因此同一栏目在首页、归档和相关文章中具有一致家族感，但不会只剩一条单调色边。

## 使用规则

没有图片时无需填写字段，组件会生成确定性 SVG：

```yaml
title: 一篇文章
columns: [engineering]
```

有真实封面时，把图片与内容共置：

```yaml
cover:
  src: ./cover.jpg
  alt: 浏览器性能面板中三段任务火焰图的对比
```

`alt` 必须说明图片中的具体信息，不写“文章封面”。横向图片建议至少 1600×700；系统会在窄卡片中使用 `object-fit: cover`，重要主体应靠近画面中心。

## 版面规则

- 首页重点文章：桌面封面为独立左栏；移动端压缩为约 5.4rem 高的校样带。
- 文章流：桌面使用 8.5rem 图块，移动端使用约 5.4rem 图块并隐藏次要摘要。
- 栏目目录：封面横跨卡片顶部，正文维持单独的信息层级。
- full/minimal 正文：真实图片或默认封面均使用约 3:1 的宽幅比例，避免封面压住正文入口。
- none 页面：发现界面有封面，独立页面内部不自动注入，避免破坏零外壳契约。
