# “某人的小站”主线视觉规格

状态：已落实，持续由浏览器与产物测试审查

日期：2026-08-28

## 方向

在原版个人博客构造和 `blog-architecture.md` 结论不变的前提下，重做配色、背景、比例和排版细节。公开身份保持简朴，不用视觉概念替代站名。现代技术感来自精确的内容层级、语义配色、细线结构与低优先级环境图形，不使用古典文案、模板化 AI 渐变或霓虹玻璃卡片。

## 页面不变量

- 首页按“站点说明 → 最近文章与搜索 → 栏目”组织；首屏不是产品 Hero；
- full 文章保留标题、摘要、日期、阅读时长、栏目、正文、目录、上下篇和读者控制；
- minimal 文章只保留返回桥、文章排版、目录与读者控制；
- none 文章与栏目只装配文档骨架及可关闭返回桥；
- 归档、关于、RSS、sitemap 和真实 URL 均属于生产结构；
- 栏目按内容分类，与文章 chrome 无关，栏目自身可以 full/minimal/none。

## 配色与背景

- `graphite`：中性石墨主主题，以冷灰正文、低饱和青绿信号和少量暖色强调构成；
- `paper`：高亮纸面主题，用于日间与长文；
- `night`：更深的无干扰主题，适合图形实验；
- `indigo`：克制靛蓝主题，提供不同阅读气质而不改变信息结构。

颜色均通过 `--bg-rgb`、`--surface-rgb`、`--text-rgb`、`--signal-rgb`、`--accent-rgb` 等语义令牌传递。环境背景由静态 CSS 网格、稀疏噪点和一次绘制 Canvas 曲线组成；主题切换或窗口变化时重绘，不运行装饰性动画循环。内容层始终有足够对比度，并能在 Canvas 失败时独立工作。

## 排版与布局

- UI/标题使用现代中文无衬线系统栈；正文使用高可读中文衬线栈；元数据使用等宽字体；
- 正文约 36–40 个中文字宽，字号可在 `.9–1.2` 比例调节；
- 桌面使用克制的非对称网格，移动端退化为单列；
- 边框以 1px 语义线为主，圆角只用于控件的小尺度反馈；
- 页面装饰不得遮挡文字、承担必要信息或制造横向溢出。

## 验收

- 1280×720 和 390×844 无横向溢出；
- full/minimal/none 文章及栏目各有代表页；
- 主题切换、搜索、移动导航、目录、字号、沉浸与返回桥可用；
- `prefers-reduced-motion` 下无装饰性持续动画；
- none 产物不含站点 Header、Footer、阅读控件、FullShell 样式或 minimal 样式；
- 类型检查、架构测试、静态构建、RSS 与 sitemap 产物检查全部通过。
