# 主线不可变约束

日期：2026-08-28

来源：`docs/source/blog-architecture.md`、冻结原型与用户明确要求。

## 权威结论

1. 项目公开名是“某人的小站”，是文章为主体的个人博客，不是作品集、SaaS 页面或概念交互展。
2. 文章内容自由度与文档外壳自由度正交；`full`、`minimal`、`none` 是页面装配，不是分类。
3. 栏目是一等内容集合，用于开发者自由定义的文章分类；栏目本身拥有与文章相同的三档网页自由度。
4. `BaseLayout` 只提供 HTML 文档骨架；导航、页脚、目录、阅读控制与返回桥均为显式加法装配。
5. 所有内容保有同域真实 URL；文章进入统一 RSS、sitemap、搜索和元数据体系。
6. 正文默认构建为静态 HTML；JavaScript 只服务实际交互。
7. 主题是语义令牌数据，DOM、Canvas 与文章/栏目私有组件共享同一语义。
8. 正文和私有组件共置；出现第二个真实消费者后再提取公共能力。
9. 正式实现使用 Astro 7、TypeScript、MDX Content Collections 与原生 CSS；不引入整站 SPA、hash 路由或默认运行时状态库。

## 视觉约束

- 视觉重做主要落实在配色、背景、排版比例、留白和细节层级；不能删除首页文章发现、文章元数据、归档、栏目、关于、RSS 等博客构造；
- 现代技术语气来自精确排版、语义颜色和克制的环境图形，不来自古典文案、模板化 AI 渐变、霓虹玻璃卡片或全站概念仪表盘；
- 背景永远是低优先级环境层：失败或静止时内容仍完整，减弱动效时不持续动画，不穿过正文阅读层级；
- Celestial Matrix 与旧单文件视觉候选均属于实验，不得进入品牌、首页结构或生产架构主轴。

## 明确禁止

- 把文章 chrome 档位当作栏目；
- 让栏目要求开发者修改核心路由或导航组件；
- 让 `none` 产物携带全站 Header、Footer、阅读控件、CSS 或服务；
- 为视觉纯度删除内容发现、真实路由、阅读工具或可访问性；
- 用新视觉概念覆盖 `blog-architecture.md` 已确定的结构结论。
