# UI 重构 V2：色谱工作台

状态：Superseded by `UI_REDESIGN_V3.md`

日期：2026-08-28

## 1. 任务定义

对象是面向开发者与长期读者的个人技术博客，首页唯一任务是让读者快速判断“这里写什么、最新且最值得读的是什么、还能从哪里继续”。文章、栏目、标签、搜索、归档和三档自由度全部保留，但不再让每种能力都表现为同等重量的模块。

## 2. 开放检索结论

- Maggie Appleton 的首页按 Essays、Notes、Patterns 等真实内容类型形成不同密度，而不是把所有入口压成相同卡片；可借鉴“结构编码内容差异”，不借用数字花园的自然/古典视觉隐喻。
- Rauno Freiberg 的页面用极少元素建立单一主张；可借鉴“首屏只允许一个视觉句号”，不借用作品集式极端留白。
- Andy Matuschak 的笔记界面让导航结构本身成为思想模型；可借鉴“栏目与关联路径可见”，但博客仍必须保留归档、搜索和稳定入口，不能取消索引。
- Josh Comeau 的文章索引使用标题、摘要和主题建立足够强的进入理由；可借鉴标题优先，不引入大批装饰性插画或交互组件。
- OKLCH 适合按感知亮度管理多色体系，但 Canvas 需要稳定读取 RGB 数值；主令牌继续输出 RGB，DOM 的装饰色可使用现代色彩混合，避免两个渲染层产生不同颜色来源。

## 3. 候选方向与批判

### A. 模块化技术仪表盘

优点是功能清楚，缺点是正好重复当前问题：暗底、青色、细边框、等尺寸卡片会让文章和工具获得同等权重，视觉上仍像可替换的 AI 前端。拒绝。

### B. 现代报刊

优点是适合长文，缺点是大衬线标题、米白纸面、密集分栏已经成为另一种模板，而且会把现代技术主题误读成古典出版。拒绝作为主方向，只保留编辑式层级。

### C. 色谱工作台

以“正在研究和写作的技术工作台”为隐喻。页面骨架安静，最新文章占据唯一视觉焦点；青、珊瑚、金、紫四种频段分别承担工程、提示、阅读和实验的路径标记。背景 Canvas 继续缓慢流动，但不承担导航或分类。采用。

## 4. 设计系统

### 色彩

默认 graphite 从近黑改为清晨蓝灰：

- Atmosphere `#1E2A36`：页面基底；
- Glass `#2A3948`：悬浮与表面；
- Polar `#F4F7F9`：主文字；
- Aqua `#7EE7D2`：工程、链接、进行中；
- Coral `#FF8068`：重点、更新、主动动作；
- Solar `#EFC477`：阅读、日期、温度；
- Iris `#BEA7FF`：图形、实验、扩展自由度。

`paper` 改成冷雾蓝而非米黄纸张，`night` 改成深海青黑，`indigo` 改成更明亮的电气暮色。四个主题共享四段色谱，但调整亮度和对比，不再每个主题只有一个强调色。

### 字体

- Display：Bahnschrift / Aptos Display / Microsoft YaHei UI，用于焦点标题，字面更紧、现代而非古典；
- UI：Segoe UI Variable / PingFang SC，用于导航、摘要和列表；
- Reading：Noto Serif SC / Source Han Serif SC，仅用于长文正文；
- Utility：Cascadia Code，用于日期、状态和短标签。

不加载外部字体，避免隐私请求和首屏阻塞。

### 布局

桌面：

```text
┌ 品牌 ───── 首页 / 文章 / 栏目⌄ / 搜索 / 关于 ─ 主题色谱 ┐
│  win98的小站            这个站写什么 / 数量 / RSS       │
│                                                        │
│  LATEST                                                │
│  最新文章的大标题（唯一主焦点）       摘要 / 日期 / 进入 │
│  ━━━━━ aqua ━ coral ━ solar ━ iris ━━━━━━━━━━━━━━━━━ │
├ 最近文章：安静时间流 ─────────┬ 栏目：彩色路径 ───────┤
│  日期  标题 / 摘要 / 标签       │ 工程实践               │
│  日期  标题 / 摘要 / 标签       │ 阅读与界面             │
│  日期  标题 / 摘要 / 标签       │ 实验                   │
└───────────────────────────────┴───────────────────────┘
```

移动端：标题、摘要、色谱、时间流、栏目依次单列；导航仍使用可关闭菜单，不牺牲搜索和主题切换。

### 标志性元素

“色谱轨”是唯一标志性元素。它连接首屏文章与内容路径，四段颜色具有固定语义；站标同步改为四条不等高的频段，不再使用容易被误读为“相位星图”的轨道图形。

## 5. 自我审查后的删减

- 删除首页即时过滤框：全文搜索已有独立页面，首屏重复搜索会分散焦点；
- 删除文章列表中的 `full/minimal/none` 徽标：它是装配自由度，不是读者分类；
- 删除栏目编号：栏目不是顺序或等级；
- 不给每个区块加卡片、阴影或圆角，只在焦点文章和交互反馈上使用表面层；
- 不新增滚动触发动画，所有动势集中到已有 Canvas；
- 不把栏目颜色写死为文章层级，色谱只作为浏览路径提示，栏目仍由开发者自由新增。

## 6. 验收

- 现有路由、搜索、标签、RSS、评论/统计适配器和三档隔离不变；
- 首页首屏只有一个主要文章入口；
- 1280×720 和 390×844 无横向溢出，标题不会遮挡导航；
- 四主题均使用多色角色，正文对比度和键盘焦点清楚；
- Canvas 动效、暂停、本地偏好、减弱动态与后台暂停全部保留。
