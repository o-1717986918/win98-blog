# Celestial Matrix 三档文章类型实验报告

日期：2026-08-28

## 结果

实验已在 `experiments/celestial-matrix/` 中完成。旧 `prototype/` 保持不变，并继续作为主线重构的产品、内容、结构与设计哲学基线。

实验名为 **Celestial Matrix / 位相星图界面**。它只用于验证 `full`、`minimal`、`none` 三档文章体验，不是博客主视觉或首页品牌轴线。

## 实现

- 冷灰复合材料底色、碳黑、光谱钴蓝、信号橙和高能黄组成五色系统；
- 超粗现代中文无衬线负责展示，窄体/等宽字体负责读数，普通无衬线负责正文；
- 首页使用不对称三栏控制台布局，大型竖排品牌栏与实时坐标矩阵形成主视觉；
- Canvas 2D 引擎生成确定性数据点、28 扇区、7 层坐标环、拓扑连线、椭圆轨道、外圈刻度和指针局部折射；
- 全屏“位相星图坐标实验”提供暂停与重新生成控制；
- 四篇示例文章使用原生 `dialog` 阅读层，支持键盘关闭与焦点恢复；
- 移动端使用独立导航层和重新编排的 hero，不再压缩桌面导航。

## 浏览器验证

桌面 1280 × 720：

- 首屏、文章阅读层和坐标实验正常；
- 页面 `scrollWidth` 与 `clientWidth` 均为 1265px；
- Canvas 以 DPR 2 渲染；
- 控制台无 error 或 warning。

移动 390 × 844：

- 页面 `scrollWidth` 与 `clientWidth` 均为 375px；
- hero、菜单、文章阅读层和坐标实验均无横向溢出；
- 菜单正确同步 `aria-expanded`；
- dialog 覆盖完整移动视口并保留可读排版。

## 工程边界

当前是隔离实验，不是最终 Astro 生产实现。正式迁移不得默认复用其视觉令牌、首页结构或坐标引擎；只有经过主线设计审查、确实服务于某篇特殊文章的能力，才可按页面独立重做。
