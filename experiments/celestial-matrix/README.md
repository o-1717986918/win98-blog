# Celestial Matrix 三档文章类型实验

这是一个零依赖、多文件的高保真实验，仅用于探索 `full`、`minimal`、`none` 三档文章类型及其交互表达。它不是“文枢手记”的第二代主视觉，不定义首页信息架构、站点品牌或生产验收标准。

## 运行

在仓库根目录执行：

```powershell
pnpm preview:experiment
```

访问 `http://127.0.0.1:8765/`。

## 文件

- `index.html`：语义结构、文章模板和交互入口；
- `styles.css`：令牌、布局、响应式和阅读界面；
- `planisphere.js`：确定性坐标场、28 扇区、拓扑连线、局部折射和绘制循环；
- `app.js`：读数、导航、文章 dialog、暂停和重新生成控制。

## 设计约束

- 仅作文章类型实验，不得直接提升为博客主线；

- 现代技术语气，不使用古典文案、仿古纹理或古籍排版；
- 不使用玻璃卡片、暗色渐变、霓虹光晕或随机漂浮粒子；
- Canvas 是内容相关的坐标系统，不是装饰背景；
- 390px 与桌面视口无横向溢出；
- 减弱动效时坐标场保持静态，仍可通过指针查看局部变化；
- 文章使用原生 `dialog`，关闭后焦点返回触发按钮。
